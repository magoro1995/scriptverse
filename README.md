# ScriptVerse

**Code through Scripture.**

ScriptVerse is an educational programming adventure where students learn real coding concepts while exploring original game campaigns inspired by the biblical narrative.

## Vision

ScriptVerse combines programming, problem solving, exploration, and Scripture-centered storytelling. Players control characters by writing code and use computational thinking to complete objectives inside original biblical worlds.

## First Campaign — Heroes of Faith

### Level 1 — Five Smooth Stones
**David & Goliath · 1 Samuel 17**

Initial gameplay goals:

- Navigate David through the Valley of Elah by writing code.
- Collect five smooth stones.
- Approach Goliath.
- Defeat Goliath with the sling.

The first programming interface is planned around commands such as:

```python
hero.moveRight()
hero.moveLeft()
hero.moveUp()
hero.moveDown()
hero.collect()
hero.attack("Goliath")
```

The player must determine the route rather than calling a destination-based pathfinding command.
